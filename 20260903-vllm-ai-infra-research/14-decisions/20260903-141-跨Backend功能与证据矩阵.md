# 跨 Backend 功能与证据矩阵

## 文档契约

- owner：功能 claim 的跨 backend 证据强度。
- 依赖输入：`02`–`13` 的固定源码事实。
- 唯一输出：不把源码存在误写成组合可用的 evidence matrix。
- 不讨论：工程成本与硬件选型；由 `142`、`144` 持有。

## 矩阵编码

本篇严格引用 02 的正交字典。为保持表格紧凑，`SI×SR` 仅是 `SOURCE_IMPLEMENTED × STATIC_REVIEWED` 的显示缩写；`UNKNOWN` 表示没有更高成熟度。不得再使用把来源与成熟度混成单轴的 S/H/D/N/T/P/R 等级。

| 能力 | Ascend | QAIC | TT | TPU |
|---|---:|---:|---:|---:|
| Platform/worker 接入 | SI×SR | SI×SR | SI×SR | SI×SR |
| 自定义 attention/KV path | SI×SR | SI×SR | SI×SR | SI×SR |
| compile/graph/artifact path | SI×SR | SI×SR | SI×SR | SI×SR |
| prefix cache capability gate | SI×SR | SI×SR/UNKNOWN-by-mode | SI×SR | SI×SR |
| device sampling | SI×SR | SI×SR/UNKNOWN-by-mode | SI×SR | SI×SR |

| structured output | SI×SR | UNKNOWN-by-mode | constrained SI×SR | SI×SR |
| multimodal | SI×SR | UNKNOWN-by-model | SI×SR-by-model | SI×SR |
| multi-device parallel | SI×SR | limited SI×SR | SI×SR | SI×SR |
| P/D 或 KV transfer | SI×SR | SI×SR/UNKNOWN-runtime | UNKNOWN | SI×SR |
| device numeric（本轮） | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |
| stress/perf（本轮） | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |

矩阵中的 `SI×SR` 只表示在固定源码找到入口、guard 或实现并完成静态可达性审阅；不表示真实设备 PASS，更不表示任意组合可乘。

## 组合主键

每一条支持记录应使用：

```text
backend tuple × hardware/topology × model implementation
× dtype/quant × eager/graph/AoT/trace
× TP/PP/DP/EP/CP × KV/prefix/offload/P-D
× LoRA/MM/spec/grammar/sampling × shape/SLO
```

## 典型不可乘组合

- TPU hybrid prefix cache + speculative decode 会触发 platform 调整/关闭。
- TT block-output model 要求同步、单 seq、无 DP、device-owned sampling 等联合约束。
- QAIC QPC 的支持面受 compile profile 和 artifact metadata 约束。
- Ascend graph replay、LoRA/MM/spec 与 topology 的组合不能由单项 feature table 推导。

## 架构决策

对用户暴露 capability 时，API 层应查询当前 effective tuple 的组合记录；找不到精确记录时返回 `UNKNOWN/unsupported`，而不是退化到 backend 名称的宽泛布尔值。自动 fallback 只有在输出、数值、RNG 和错误语义等价时才可透明。

## 结论

- `SOURCE_IMPLEMENTED`：矩阵由固定源码的 capability/guard/objects 汇总。
- `RECOMMENDATION`：CI 与文档共用 machine-readable combination matrix。
- `UNKNOWN`：所有高于 `STATIC_REVIEWED` 的运行成熟度，除非后续附真实 artifacts；release contract 必须独立列为来源类型。
